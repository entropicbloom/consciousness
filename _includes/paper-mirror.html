{%- comment -%} Body of the plain-markdown mirror, shared by /paper.md and /paper.txt. Two paths serve these identical bytes because GitHub Pages picks the response Content-Type from the extension and offers no way to override it. .md is served as text/markdown, which some agent fetchers reject outright as an unsupported content type; .txt is served as text/plain, which they accept. Keeping both means the self-describing URL still works wherever text/markdown is understood. Neither generator may carry a .md extension -- kramdown would convert it and emit HTML into the permalink. With .html, Liquid runs but no markdown conversion happens, so the includes pass through as literal markdown.
